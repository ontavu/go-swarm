# go-swarm

Read [README.md](README.md) first: it says what the package does and who uses it. This
file holds the rules for changing it.

## Commands

```sh
go build ./...
go vet ./...
gofmt -l .              # must print nothing
go test -race ./...
go mod tidy             # and go.mod must not change
```

`.github/workflows/ci.yml` gates on all five. Run tests with `-race` every time: a group
is goroutines sharing a cancel, a `WaitGroup` and a counter.

## What may be imported

**The standard library, and nothing else.** `go.mod` has no `require`, and has to keep
none: every module that supervises its goroutines with this one would inherit the
dependency. No other ontavu module either, since they are the ones importing this one.

```sh
go list -deps -f '{{if not .Standard}}{{.ImportPath}}{{end}}' ./...   # github.com/ontavu/go-swarm, alone
```

Code that lands here takes the MPL-2.0. Nothing proprietary may come in: `cams-hub` is
proprietary, and code leaves it only on purpose.

## Attribution: `Assisted-By`, never `Co-Authored-By`

A model is a tool, not an author. Work an assistant helped with ends its commit message,
and its pull request description, with one line: `Assisted-By: Claude Code`,
`Assisted-By: Codex`, and so on.

- **The tool, not the model.** Model names change every few months; the tool is what was
  actually run.
- **No address**, and no `Co-Authored-By`. Git and GitHub read that trailer as a person.
  In a copyleft project the authors are the copyright holders, and they are listed in
  `AUTHORS`.
- **Nothing in the sources.** No `// generated by` and no model name anywhere.

## The contracts the tests pin

Each of these broke once, or is one edit away from breaking, and each has its test:

- **`Run` and `EnsembleRun` defer `Cancel` and then `Wait`**, so that `Wait` runs first.
  Swapping them makes `Run` cancel the members it has just started, which
  `TestRun_HonoursTheCallersContext` catches.
- **A member is counted before `Run` returns**, not when its goroutine starts, so that
  `Count()` never reports an idle group that is not. `TestSwarm_CountCountsLiveMembers`.
- **The decrement is `minusOne`, exactly `math.MaxUint32`.** `MaxUint32-1` subtracts 2;
  `TestSwarm_CountReturnsToZero` is its regression test.
- **A Swarm member's return releases nobody; an Ensemble member's releases everyone.**
  That difference is the reason both kinds exist.

## Releases

Cams requires this module by its tag, never through a `replace`: its CI and its Docker
build see only the repository being built. A change therefore reaches its users in three
steps:

1. Merge it here, then tag `vX.Y.Z` and push the tag. Stay below v1 while the API moves.
   **Push the tag before any module requires it**: a version asked for before it exists is
   remembered as missing by the Go checksum database for about half an hour.
2. `go get github.com/ontavu/go-swarm@vX.Y.Z`, then `go mod tidy`, in `cams-hub/go/` of
   ontavu/cams and in ontavu/cams-agent.
3. Make any signature change on their side in the same change as the bump.

To develop several modules at once, put a `go.work` in the directory that holds the
clones. Commit it to no repository; `.gitignore` excludes it.

## Go rules

These are the rules of the Cams project (see its `AGENTS.md`), and they apply here as
written:

- New logic ships with its tests.
- No error is silently ignored.
- No goroutine leaks, and whoever cancels also waits.
- No buffer grows without bound.
